# BioLaySumm - Medical Report Simplification with FLAN-T5

Fine-tuning FLAN-T5-base to translate expert radiology reports into layperson summaries.

## Model Specifications
- **Base Model:** FLAN-T5-base (google/flan-t5-base)
- **Total Parameters:** 249,347,328 (~249M)
- **Trainable Parameters:** 1,769,472 (0.71%) with LoRA
- **LoRA Rank:** 16

## Training Configuration
- **Batch Size:** 16
- **Learning Rate:** 5e-5
- **Epochs:** 5
- **Max Length:** 512 tokens
- **Training Samples Used:** 15,000 (subset of 150,454 total)

## Usage

### Training
```bash
python train.py
```

### Inference
```bash
python predict.py
```


## Files
- `dataset.py` - Data loading
- `modules.py` - Model components
- `train.py` - Training script
- `predict.py` - Inference examples

## Detailed Model Architecture

### FLAN-T5 Base
- **Architecture:** T5-style encoder-decoder transformer
- **Encoder-Decoder:** Seq2seq model for text generation
- **Pre-training:** Instruction-tuned on diverse tasks

### LoRA Configuration
- **Target Modules:** ["q", "v"] - Query and Value projection layers
- **LoRA Alpha:** 32
- **LoRA Dropout:** 0.1
- **Task Type:** SEQ_2_SEQ_LM

## Training Strategy

### Training using prompt

**Experiment 1 & 2**

**Prompt:**
```
"Translate into plain language for a general audience: "
```

**Experiment 3 Enhanced Prompt (Best Results):**
```
"Simplify this medical report for a patient. Replace technical terms with everyday words and explain what they mean: "
```

The enhanced prompt in Experiment 3 provides more specific instructions, explicitly guiding the model to:
1. Target a patient audience (layperson perspective)
2. Replace technical terms (active simplification)
3. Explain meanings (add explanatory context)

This more directive approach resulted in significantly better ROUGE scores and genuine medical terminology simplification.

### Optimization
- **Optimizer:** AdamW
- **Learning Rate:** 5e-5
- **Training Loop:** Standard supervised learning
  - Forward pass with teacher forcing
  - Compute cross-entropy loss
  - Backward pass and parameter update

### Validation
- Validation performed after each epoch
- Metrics: Loss and ROUGE scores
- Early stopping can be implemented based on validation loss

## Evaluation Metrics

### ROUGE Scores
ROUGE (Recall-Oriented Understudy for Gisting Evaluation) measures overlap between generated and reference summaries:

- **ROUGE-1:** Unigram (single word) overlap
- **ROUGE-2:** Bigram (word pair) overlap
- **ROUGE-L:** Longest common subsequence
- **ROUGE-Lsum:** LCS at summary level (multi-sentence)

### Training Results

#### Experiment 1: 15,000 Training Samples
- **Training samples:** 15,000
- **Training time:** 1h 22m 32s
- **Final train loss:** 0.2088
- **Final validation loss:** 0.1849
- **ROUGE-1:** 0.4852 (48.52%)
- **ROUGE-2:** 0.2226 (22.26%)
- **ROUGE-L:** 0.4151 (41.51%)
- **ROUGE-Lsum:** 0.4151 (41.51%)

#### Experiment 2: 30,000 Training Samples
- **Training samples:** 30,000
- **Training time:** 2h 25m (8,700 seconds)
- **Final train loss:** 0.1524
- **Final validation loss:** 0.1403
- **ROUGE-1:** 0.6437 (64.37%)
- **ROUGE-2:** 0.4471 (44.71%)
- **ROUGE-L:** 0.5686 (56.86%)
- **ROUGE-Lsum:** 0.5678 (56.78%)

**Observation:** Increasing training data from 15k to 30k samples resulted in substantial improvements across all ROUGE metrics. ROUGE-1 improved by 15.85 percentage points (48.52% → 64.37%), ROUGE-2 improved by 22.45 percentage points (22.26% → 44.71%), and ROUGE-L improved by 15.35 percentage points (41.51% → 56.86%). This demonstrates the critical importance of sufficient training data for medical text simplification tasks. However, complex medical vocabulary still remains in the predictions, indicating that the model has not fully learned to simplify technical terms. The high ROUGE scores may be partially due to the predictions not differing significantly from the input text rather than achieving genuine simplification.

#### Experiment 3: 75,000 Training Samples with Enhanced Prompt (Best Model)
- **Training samples:** 75,000 (50% of full dataset)
- **Training time:** 4h 38m (16,703 seconds)
- **Prompt:** "Simplify this medical report for a patient. Replace technical terms with everyday words and explain what they mean: "
- **Final train loss:** 0.9518
- **Final validation loss:** 0.8817
- **ROUGE-1:** 0.7337 (73.37%)
- **ROUGE-2:** 0.5709 (57.09%)
- **ROUGE-L:** 0.7059 (70.59%)
- **ROUGE-Lsum:** 0.7052 (70.52%)

**Observation:** Combining 2.5x more training data with an enhanced prompt yielded the best results. ROUGE-1 improved by 9 percentage points (64.37% → 73.37%), ROUGE-2 by 12.38 points (44.71% → 57.09%), and ROUGE-L by 13.73 points (56.86% → 70.59%) compared to Experiment 2. The enhanced prompt's explicit instruction to "replace technical terms with everyday words and explain what they mean" successfully guides the model to provide genuine simplification with explanatory definitions (e.g., "COPD, which is a long-term lung condition"). This demonstrates that a stronger prompt combined with sufficient training data is critical for achieving better performance in medical text simplification.

## Model Performance Analysis

### Experiment 3 (Best Model) - 75k Samples + Enhanced Prompt

The final FLAN-T5 model demonstrates strong performance in medical text simplification with a ROUGE-1 score of 0.7337 and ROUGE-2 score of 0.5709. Analysis of generated outputs reveals significant improvements over earlier experiments:

#### Strengths:

1. **Effective Terminology Simplification:** The model successfully replaces complex medical jargon with layperson-friendly language. Examples include:
   - "costophrenic angle" → "angle where the chest wall meets the diaphragm"
   - "pulmonary parenchyma" → "lungs"
   - "cardiomediastinal silhouette" → "area around the heart"

2. **Explanatory Definitions:** Following the enhanced prompt's guidance, the model provides helpful explanations:
   - "COPD, which is a long-term lung condition"
   - "calcified granuloma, which is a type of hardened lump"

3. **Factual Accuracy:** Critical medical information is consistently preserved across all examples while being made more accessible.

4. **Fluency:** Generated outputs maintain grammatical correctness and natural sentence structure suitable for patient communication.

5. **High ROUGE Scores:** Individual examples achieve ROUGE-1 scores up to 0.8451 and ROUGE-2 up to 0.7018, indicating strong alignment with reference simplifications.

#### Remaining Challenges:

1. **Partial Retention of Technical Terms:** Some complex terminology occasionally remains, though significantly less than in earlier experiments.

2. **Variable Simplification Depth:** Simplification quality varies across examples, with some achieving near-perfect layperson language (ROUGE-1: 0.84) while others are more moderate (ROUGE-1: 0.59).

#### Overall Assessment:

The Experiment 3 model achieves excellent ROUGE scores (ROUGE-1: 0.73, ROUGE-2: 0.57, ROUGE-L: 0.71), demonstrating that combining increased training data (75k samples) with a more directive prompt significantly improves medical text simplification. The model successfully performs the core task of genuine simplification, converting technical medical vocabulary to patient-friendly language while maintaining accuracy. The ROUGE-2 score of 57% indicates strong preservation of medical facts and relationships, making this model suitable for real-world medical text simplification applications. The success of this experiment validates the importance of both sufficient training data (50% of the full dataset) and carefully engineered prompts that explicitly guide the model's simplification behavior.

### Progressive Improvement Across Experiments

**Experiment 1 (15k samples):** Basic simplification capability established (ROUGE-1: 0.49)
**Experiment 2 (30k samples):** Significant improvement with more data (ROUGE-1: 0.64)
**Experiment 3 (75k samples + enhanced prompt):** Best results with data scaling and prompt engineering (ROUGE-1: 0.73)

## Memory Optimization

If encountering CUDA Out of Memory (OOM) errors:

### 1. Reduce Batch Size
```python
BATCH_SIZE = 2  # or even 1
```

### 2. Reduce Sequence Length
```python
MAX_LENGTH = 256  # instead of 512
```

### 3. Gradient Accumulation
```python
accumulation_steps = 4
for batch_idx, batch in enumerate(train_loader):
    loss = compute_loss(batch)
    loss = loss / accumulation_steps
    loss.backward()

    if (batch_idx + 1) % accumulation_steps == 0:
        optimizer.step()
        optimizer.zero_grad()
```

### 4. Mixed Precision Training
```python
from torch.cuda.amp import autocast, GradScaler

scaler = GradScaler()
for batch in train_loader:
    with autocast():
        outputs = model(**batch)
        loss = outputs.loss

    scaler.scale(loss).backward()
    scaler.step(optimizer)
    scaler.update()
    optimizer.zero_grad()
```
